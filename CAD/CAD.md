## CAD Folder

This folder contains all files related to the mechanical design of the project. Here you will find 3D models, technical drawings, and documentation for the physical structure of the robot or device.

### Example Files
- `chassis.step`: 3D model of the robot chassis
- `arm.stl`: 3D printable file for a robotic arm
- `assembly.dwg`: Technical drawing for assembly
- `readme.txt`: Additional documentation or notes
